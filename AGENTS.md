## Agent skills

### Issue tracker

Tickets locais em Markdown sob `.scratch/pulso/`. Consulte `docs/agents/issue-tracker.md` ao planejar, buscar, implementar ou encerrar tickets.

### Triage labels

Os cinco rótulos padrão das Matt Pocock Skills. Consulte `docs/agents/triage-labels.md` ao classificar tickets.

### Domain docs

Layout single-context: `GLOSSARY.md` e `docs/adr/` na raiz. Consulte `docs/agents/domain.md` antes de explorar ou alterar uma área do domínio.
