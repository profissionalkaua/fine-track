# Triage Labels

Os rótulos adotados são os padrões das Matt Pocock Skills.

| Papel | Rótulo local | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Solicitação aguardando avaliação. |
| needs-info | needs-info | Faltam informações de quem solicitou. |
| ready-for-agent | ready-for-agent | Trabalho especificado e disponível para implementação pelo agente. |
| ready-for-human | ready-for-human | Trabalho que exige execução humana. |
| wontfix | wontfix | Solicitação que não será implementada. |

Estes rótulos descrevem triagem. `claimed` e `resolved` descrevem execução, conforme `issue-tracker.md`.
